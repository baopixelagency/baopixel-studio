## 🎬 PIPELINE CRM - Scripts de Prospection

### Prospect Froid
```
Bonjour {{nom}} 👋

Je suis Norta de BaoPixel Digital Agency, basée à Mbour. 
Nous aidons les entreprises de la Petite-Côte à dominer leur 
présence visuelle (photo, vidéo, drone, réseaux).

Vous seriez intéressé par un appel de 15min cette semaine ?
```

### Prospect Chaud - Email de Relance
```
Bonjour {{nom}},

Suite à notre discussion, j'aimerais revenir verso vous concernant 
nos services. Nos packs commencent à 150 000 FCFA/mois avec livraison 
hebdomadaire.

Quand pourrions-nous discuter plus en détail?

Cordialement,
Norta — BaoPixel 🎥
```

## 📅 CALENDRIER ÉDITORIAL - Idées Contenu

### Format: Génération d'idées pour une semaine

```
Génère un calendrier éditorial pour la semaine du 31 mars 2026.

Contexte:
- Agence: BaoPixel Digital (vidéo, drone, photo)
- Audience: Entrepreneurs et agences de la Petite-Côte
- Réseaux: Instagram + TikTok
- 3 publications par semaine
- Formats: Reels, Carrousels, Stories

Piliers de contenu:
1. Montrer (Behind-the-scenes, processus)
2. Éduquer (Tips marketing, algo)
3. Prouver (Cas clients, résultats)
4. Personal Brand (Fondateur Norta)

Format de réponse:
LUN: [Titre] | [Format] | [Angle]
MAR: ...
```

### Pour un client spécifique (Hôtel)

```
Génère 5 idées de contenu pour So Suite Hôtel (4 étoiles, Petite-Côte).

Objectifs:
- Augmenter les réservations
- Montrer ambiance et services
- Engager les touristes et voyageurs

Ideas:
1. Format | Plateforme | Description courte
2. ...

Chaque idée doit être réalisable en <30 minutes.
```

### Stratégie contenu mensuelle

```
Plan de contenu pour {{client}} — {{mois}}.

Secteur: {{secteur}}
Budget: {{montant}} FCFA
Objectif: {{objectif}}

Génère:
1. 4 piliers de contenu prioritaires
2. 3 idées par pilier pour le mois
3. Types de contenu à privilégier
4. Meilleure heure de publication
5. Hashtags à utiliser
6. Métriques à suivre

Format: réponse COURTE et structurée, actionnable immédiatement.
```

## 💰 TRÉSORERIE - Analyses Financières

### Analyse de rentabilité

```
Analyse la rentabilité de BaoPixel pour {{mois}}.

CA:
- Detmine Immo: 150,000 FCFA
- So Suite Hôtel: 200,000 FCFA
- NaySeet Cosmetics: 120,000 FCFA
Total: 470,000 FCFA

Dépenses fixes:
- Déplacements: 30,000 FCFA
- Abonnements outils: 15,000 FCFA
- Charges diverses: 20,000 FCFA
Total: 65,000 FCFA

Dépenses d'investissement:
- Dépense MacBook: 350,000 FCFA

Questions:
1. Suis-je rentable? (Marge nette %)
2. Objectif mensuel atteignable? (Visé: 700k)
3. Recommandations pour augmenter CA?
4. Risques à surveiller?
```

### Prévisions trimestrielles

```
Fais une prévision de cash-flow pour Q2 2026 (Avril-Mai-Juin).

Données actuelles:
- CA moyen: 470k FCFA/mois
- Croissance estimée: +10%/mois
- Clients actuels: Detmine (récurrent), So Suite (prospect chaud), NaySeet (prospect)

Hypothèses:
- So Suite devient client actif: +200k
- Nouvelle acquisition/mois: +50k

Génère:
1. Projection CA par mois
2. Dépenses estimées
3. Points sensibles (tresorerie critique?)
4. Recommandations
```

## 📊 REPORTING - Analyse Performance Clients

### Format automatesque rapport

```
Génère un rapport de performance pour {{client}} — {{mois}}.

KPIs réels:
- Abonnés: {{followers}}
- Reach: {{reach}}
- Engagement: {{engagement}}%
- Posts publiés: {{posts}}
- Notes: {{notes}}

Rapport doit inclure:
1. 📊 Résumé exécutif (2 phrases)
2. 🎯 Points forts (3 points)
3. ⚠️ Points d'amélioration (3 points)
4. 💡 Recommandations (3 actions)
5. 📅 Plan d'action mois prochain
6. 🎯 Objectifs pour mois prochain

Ton: professionnel, positif, actionnable.
Contexte: BaoPixel Digital Agency, agence spécialisé vidéo/drone.
```

### Benchmark secteur

```
Compare la performance réseaux du {{client}} ({{secteur}}) 
avec la moyenne du secteur en Afrique de l'Ouest.

Client KPIs:
- Abonnés: {{followers}}
- Reach: {{reach}}
- Engagement: {{engagement}}%
- Croissance mensuelle: {{growth}}%

Analyse:
1. Par rapport à la moyenne secteur, c'est...?
2. Points forts comparatifs
3. Points à améliorer
4. Stratégies des concurrents à copier
5. Tendances du secteur
```

## 📁 DECKS & DOCS - Documents Professionnels

### Proposition Commerciale Template

```
Génère une proposition commerciale professionnel pour {{client}}.

Détails client:
- Nom: {{nom}}
- Secteur: {{secteur}}
- Budget: {{montant}} FCFA/mois
- Contexte: {{notes}}

Proposition doit inclure:
1. En-tête (Logo BaoPixel, date, client)
2. Sommaire
3. Situation actuelle (le problème du client)
4. Objectifs (ce qu'on veut achiever)
5. Notre solution (packs + services)
6. Tarification transparente
7. Calendrier / Livrables
8. Prochaines étapes
9. Signature

Ton: confiant mais humblement, français impeccable, mise en forme claire.
```

### Brief Créatif

```
Génère un brief créatif pour {{client}} ({{secteur}}).

Objectif de campagne: {{objectif}}
Format: {{format}} (Vidéo, Phot, Reel, etc.)
Plateforme: {{plateforme}} (Instagram, TikTok, Facebook)

Brief doit inclure:
1. Contexte / Background
2. Objectifs SMART
3. Public cible (persona)
4. Message clé à passer
5. Tone of voice
6. Éléments à inclure (logos, hashtags, etc.)
7. Contraintes techniques
8. Processus de création (planning)
9. Critères de succès

Exemple réel:
- Client: Détmine Immo
- Format: Vidéo propriété 60s
- Plateforme: Instagram Reels
- Message: "Nouveau T5 avant/après"
```

### Onboarding Client

```
Génère un document d'onboarding pour {{client}} (nouveau client).

Ce document doit:
1. Accueillir chaleureusement le client
2. Expliquer le processus de travail (5 étapes)
3. Lister les responsabilités du client (infos, images, retours)
4. Donner un quick-start guide
5. Calendrier des livrables
6. Contacts et support (Notre équipe)
7. FAQ (5 questions fréquentes)
8. Ressources (guides, références)

Ton: amical, rassurant, clair.
```

## 🎯 GUIDE ALGO - Réponses Techniques

### Instagram Algorithm 2026

```
Explique-moi l'algorithme Instagram en 2026.

Je suis: Agence audiovisuelle basée à Mbour, Sénégal.
Mes clients: Hôtels, restaurants, agences immo, spas.
Mon objectif: Augmenter reach et engagement.

Réponds avec:
1. 🎯 Principe clé (quoi it changed depuis 2025?)
2. ✅ Ce que je dois faire (3 actions)
3. ❌ Ce que je dois éviter (3 erreurs courantes)
4. 💡 Astuce BaoPixel (specifique à notre niches)
5. 📊 Métriques à surveiller
6. 📈 Stratégie contenu optimisée
```

### TikTok Strategy Afrique

```
Quelle stratégie TikTok pour une agence vidéo en Afrique de l'Ouest?

Contexte:
- Audience: Créateurs de contenu, entrepreneurs
- Niches: Immobilier, hôtellerie, bien-être, restoration
- Objectif: Brand awareness + lead gen

Réponds:
1. Format contenu à privilégier
2. Fréquence de publication optimale
3. Utilisations des sons / trends
4. Growth hacking spécifique TikTok
5. Conversion TikTok → Clients payants
6. Budget Google Ads pour TikTok (optionnel)
7. Erreurs à éviter
```
